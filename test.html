🔍 5. 브라우저 콘솔 확인

게임을 열고 F12를 눌러 개발자 도구를 열어주세요.

확인 사항:

  • 빨간색 에러가 없어야 함
  • Supabase 관련 에러가 없어야 함
  • "Anonymous sign in error" 메시지가 없어야 함
  • "Save game error" 메시지가 없어야 함

🗄️ 6. 데이터베이스 데이터 확인

Supabase Table Editor에서 데이터를 확인하세요:

📊 Table Editor 열기

확인 사항:

  • game_progress 테이블에 레코드가 생성되었는지
  • wave, turn 값이 올바른지
  • heroes, monsters, grid JSON 데이터가 있는지
  • best_wave 값이 업데이트되는지
